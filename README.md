# 📱 Flutter E-Commerce Demo

Aplicación desarrollada en Flutter que consume una API de productos para mostrar un catálogo tipo tienda.

---

## 🚀 Objetivo del proyecto

Este proyecto tiene como objetivo:

- Aprender desarrollo de aplicaciones móviles con Flutter
- Consumir APIs externas
- Mostrar productos en una interfaz moderna
- Construir una base para futuras apps más completas

---

## 🛠️ Tecnologías utilizadas

- Flutter
- Dart
- API REST (Fake Store API)
- Git & GitHub
